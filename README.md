# Serrajordi-Diaz Investments · C/ Anselm Clavé 30

Web de la primera promoció de Serrajordi-Diaz Investments: dues cases adosades d'obra nova a Llinars del Vallès.

- Recorregut en 3D amb scroll pel carrer i el solar, amb el sol real de cada hora.
- Maqueta explorable (vista aèria, a peu de carrer i planta).
- Hores de sol per mes i hora, calculades amb les ombres dels edificis veïns.
- Simulador orientatiu de la quota de la hipoteca.

La maqueta usa la geometria de la Direcció General del Cadastre i un motor WebGL 2 propi, sense dependències.

## Estructura
- `index.html`: la web publicada (un sol fitxer).
- `src/`: codi font. `sh build.sh` torna a generar `index.html`.
